# IPhySims Website

Official website of the International Physics Simulation Society (IPhySims).

## Deployment

This website is deployed at: https://iphysim.org

## Development

The website is built with HTML and Tailwind CSS.

### Local Development

Simply open `index.html` in a web browser.

### Deployment Options

1. **GitHub Pages**: Enable GitHub Pages in repository settings
2. 2. **Vercel**: Connect repository to Vercel for automatic deployments
   3. 3. **Netlify**: Connect repository to Netlify
     
      4. ## Content
     
      5. - `index.html` — Main website (single-page application)
