What is IPhySims?

An independent, international, non-profit organization establishing the gold standard for physics simulation quality.

Certification Body

The authoritative certification body for physics simulations, similar to how ISO certifies quality management systems.

Standards Organization

We establish rigorous standards for scientific accuracy, code quality, reproducibility, and educational value.

International Scope

A global community of physicists, educators, and developers advancing computational physics together.

Certification Standards

Every simulation undergoes rigorous evaluation across four dimensions.

40%

Scientific Accuracy

Correctness of physical models and validation against known solutions.

25%

Code Quality

Clean, documented, tested code following open-source best practices.

20%

Reproducibility

Consistent results across platforms with clear instructions.

15%

Educational Value

Effective demonstration of physical concepts with documentation.

Review Process

Submission → Screening → Peer Review (×2) → Revision → Editorial Decision → Publication
